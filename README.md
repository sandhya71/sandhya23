## What's inside

```
sandhya-portfolio/
├── index.html       ← Full portfolio (dark editorial, single page)
├── README.md        ← This file
└── .nojekyll        ← Tells GitHub Pages to serve index.html as-is
```

## Deploy instructions

1. Create a new GitHub repo named **`sandhya71.github.io`** (Settings → Pages)
2. Upload this entire folder's contents to the root of that repo
3. Go to **Settings → Pages → Source → Deploy from branch → main / root**
4. Done — your portfolio is live at `https://sandhya71.github.io`
